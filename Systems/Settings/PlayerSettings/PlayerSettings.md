#### Description

PlayerSettings is a [ScriptableObject](https://docs.unity3d.com/6000.3/Documentation/Manual/class-ScriptableObject.html) that stores a set of settings.

The default settings are stored in `Resources/DefaultPlayerSettings.asset`

#### Shape

```json
{
  "cameraSensibility": 10.0
}
```
